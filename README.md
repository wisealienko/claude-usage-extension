# Claude Usage — паспорт расширения

Расширение для Google Chrome, которое показывает расход лимитов Claude прямо на странице claude.ai: текущую пятичасовую сессию и недельный лимит, с цветной полоской и временем сброса.

| | |
|---|---|
| Версия | 0.3 |
| Тип | Chrome Extension, Manifest V3 |
| Где работает | только `https://claude.ai/*` |
| Проверено | Chrome на macOS Big Sur 11.7, тариф Pro |
| Дата | 22.10.2026 |

---

## 1. Что делает

Плашка показывает две строки данных:

- **Сессия** — процент израсходованного пятичасового лимита и время его сброса.
- **Неделя** — процент израсходованного недельного лимита и день и время его сброса.

Каждая строка сопровождается полоской. Цвет полоски зависит от расхода: при 0% она синяя, по мере роста становится фиолетовой.

### Три режима (переключаются нажатием на иконку расширения)

```
закреплена  →  свободная  →  скрыта  →  закреплена  → …
```

| Режим | Как выглядит | Поведение |
|---|---|---|
| **Закреплена** | Над полем ввода, на всю его ширину, сессия и неделя в одну строку | Двигается вместе с полем ввода. Перетаскивать нельзя. Лежит на уровне страницы: окна сайта (например, настройки) её закрывают |
| **Свободная** | Компактная плашка 210 px, две строки | Можно перетащить мышкой куда угодно, место запоминается. Всегда поверх всего |
| **Скрыта** | Не видна | Запросы к серверу не отправляются |

Если в режиме «закреплена» на странице нет поля ввода, плашка временно показывается в свободном виде. Когда поле появится, она снова закрепится.

### Когда обновляются цифры

- при открытии или перезагрузке страницы;
- автоматически каждые 60 секунд (кроме режима «скрыта»);
- по клику на значок ↻ у любой из строк (плашка на полсекунды становится полупрозрачной);
- при переключении иконкой в видимый режим.

## 2. Установка

1. Скачать папку расширения (этот репозиторий).
2. Открыть `chrome://extensions`.
3. Включить **Режим разработчика** (справа вверху).
4. Нажать **Загрузить распакованное** и выбрать папку.
5. Обновить вкладку claude.ai.
6. Закрепить иконку на панели: значок пазла справа от адресной строки → булавка у Claude Usage.

После изменения файлов: нажать ⟳ на карточке расширения в `chrome://extensions` **и** обновить вкладку claude.ai.

## 4. Как устроено

### Источник данных

Данные берутся из **внутреннего** запроса claude.ai — того же, который использует страница *Настройки → Использование*:

```
GET https://claude.ai/api/organizations/{ID организации}/usage
```

Запрос выполняется со страницы claude.ai, поэтому сайт видит обычные cookies входа пользователя. Ключи, пароли и токены расширение не хранит и не запрашивает.

Используемые поля ответа:

| Поле | Что значит |
|---|---|
| `five_hour.utilization` | Расход сессии, % |
| `five_hour.resets_at` | Время сброса сессии (UTC) |
| `seven_day.utilization` | Расход за неделю, % |
| `seven_day.resets_at` | Время сброса недели (UTC) |

Время в ответе приходит в UTC и показывается в часовом поясе компьютера.

### ID организации

Каждый аккаунт claude.ai, даже личный, привязан к «организации» со своим ID. Расширение определяет его само при каждом обновлении:

1. берёт из cookie `lastActiveOrg` — это организация, выбранная сейчас;
2. если cookie нет — запрашивает `GET /api/organizations` и берёт первую организацию из списка.

Два источника вместо одного — на случай, если сайт уберёт один из них. Благодаря этому плашка сама подхватывает смену аккаунта или организации.

### Закрепление над полем ввода

1. Находится поле, куда пишется текст: элемент с меткой `data-testid="chat-input"`.
2. От него расширение поднимается вверх по вложенным элементам (не больше 10 уровней) и берёт **первый со скруглёнными углами и непрозрачным фоном** — это видимая рамка поля.
3. Плашка ставится над рамкой с отступом 6 px и принимает её ширину. Положение пересчитывается каждый кадр, поэтому плашка следует за полем, когда оно растёт от длинного текста или меняется размер окна.

Рамка ищется по устройству страницы, а не по CSS-классам (`bg-surface-3` и т. п.): классы сайт может поменять при любом обновлении. Если поле не найдено, повторный поиск выполняется не чаще раза в 0,5 с.

### Слои (z-index)

| Режим | z-index | Почему |
|---|---|---|
| Закреплена | `1` | На уровне страницы: всплывающие окна сайта закрывают плашку так же, как закрывают само поле ввода |
| Свободная | `99999` | Всегда видна, в том числе поверх окна настроек |

## 5. Принятые решения и их причины

| Решение | Почему так |
|---|---|
| Внутренний запрос claude.ai, а не публичный Claude API | Публичный API (с API-ключом) считает отдельный расход разработчика и ничего не знает о лимитах подписки |
| Никаких `permissions` в манифесте | Расширению не нужен доступ ни к чему, кроме страниц claude.ai, куда оно и так встраивается. Для отправки команды с иконки на вкладку разрешение не требуется |
| Цвет по расходу (hue 217° → 275°), а не постоянный градиент | Цвет сразу сообщает, много ли израсходовано |
| Перетаскивание только в свободном режиме | Закреплённая плашка привязана к полю ввода |
| Клик по ↻ не срабатывает после перетаскивания | Если мышь сдвинулась больше чем на 3 px между нажатием и отпусканием, это считается перетаскиванием, а не кликом |
| Свободная плашка не выходит за края окна | При перетаскивании и восстановлении места координаты ограничиваются размерами окна |
| Окна сайта закрывают закреплённую плашку за счёт z-index, без отслеживания | Рассматривалась проверка «не закрыто ли поле ввода» (`elementFromPoint`). Отклонена: она срабатывает и на меню «+», выбор модели, подсказки, перетаскивание файла — плашка прыгала бы в угол и обратно |
| В скрытом режиме автообновление не работает | Нет смысла отправлять запросы, которые никто не видит |

## 6. Что хранится

Только в `localStorage` сайта claude.ai, в браузере пользователя. Никуда не отправляется.

| Ключ | Что хранит |
|---|---|
| `claude-usage-mode` | Текущий режим: `dock`, `float` или `hidden` |
| `claude-usage-pos` | Координаты свободной плашки, `{left, top}` в пикселях |
| `claude-usage-hidden` | Устаревший ключ от первого варианта кнопки «показать/скрыть». Читается, только если `claude-usage-mode` ещё не задан |

Сетевые запросы идут только на claude.ai.

## 7. Ограничения и риски

- **Неофициальный API.** Запросы `/usage` и `/organizations` не документированы. После обновления claude.ai они могут поменяться, и плашка покажет «Claude Usage: ошибка».
- **Несколько вкладок claude.ai** — в каждой работает своя копия плашки со своими запросами раз в минуту. Режим и место общие (хранятся в `localStorage`), но в других вкладках применятся после их перезагрузки.
- **Шаг процентов** — сервер отдаёт расход с округлением, поэтому одно-два коротких сообщения могут не сдвинуть цифру.
- **Режим разработчика.** Расширение установлено как распакованное; Chrome может иногда напоминать об этом.
- **Нажатие на иконку на других сайтах** ничего не делает.
- **Поиск рамки** опирается на `data-testid="chat-input"`. Если сайт уберёт эту метку, закреплённый режим будет показываться как свободный.

## 8. Если что-то сломалось

**Плашка пишет «Claude Usage: ошибка»**

1. Открыть DevTools → Console: расширение пишет туда подробности ошибки с префиксом `Claude Usage:`.
2. Открыть *Настройки → Использование*, в DevTools → Network включить фильтр **Fetch/XHR**, обновить страницу.
3. Найти запрос со словом `usage`, посмотреть его адрес и ответ.
4. Сравнить с разделом 4 и поправить адрес или имена полей в `content.js`.

**Плашка не закрепляется над полем ввода**

В Console выполнить:

```js
document.querySelector('[data-testid="chat-input"]')
```

Если результат `null` — сайт поменял метку поля, нужно найти новую.

**Изменения в файлах не применились** — нажать ⟳ в `chrome://extensions` и обновить вкладку claude.ai.
